# drownman
a game like the classic hangman but the man drowns instead of hanging.

![winning screen](./assets/win.png)
losing screen

## features
- a keypad to guess the letter and the letters which are already guessed
- when letter guessed its bg color change
- total number of incorrect guesses
- waves of water coming up after every incorrect guess eventually covering the whole screen and drowning you
